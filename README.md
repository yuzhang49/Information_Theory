# Information Theory
This repository contains all lecture slides for ECE253/CSE208 "Introduction to Information Theory" at the University of California, Santa Cruz. 
The slides mainly cover Chapters 1-10 of the textbook: Elements of Information Theory (2nd Edition, Wiley-Interscience) by Thomas Cover and Joy Thomas.
For comments or suggestions, please contact Dr. Yu Zhang (zhangy@ucsc.edu), ECE Department, UC Santa Cruz. Homepage: https://people.ucsc.edu/~yzhan419/
