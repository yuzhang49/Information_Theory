# Information Theory

This repository contains the lecture slides for **ECE253/CSE208: Introduction to Information Theory** at the **University of California, Santa Cruz (UCSC)**.

The slides primarily cover **Chapters 1–10** of the textbook:

**Thomas M. Cover and Joy A. Thomas**,  
*Elements of Information Theory*, 2nd Edition, Wiley-Interscience.
